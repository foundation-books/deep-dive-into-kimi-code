# Chapter 2 CPU reference

The module reference.py implements the chapter's scaled-down computational
contracts with Python's standard library. It is an arithmetic and state oracle,
not an optimized model implementation.

Run the unit tests from the companion-code root:

    python3 -B _maintenance/chapter_test_runner.py \
      computational_anatomy/test_computational_anatomy_reference.py

The evidence runner under experiments/computational_anatomy records the six
named checks, the command, and the host/software manifest.
